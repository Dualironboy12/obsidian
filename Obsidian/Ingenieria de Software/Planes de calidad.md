# Que responde un plan de calidad?
## QUE se valida?
ISO 25010 es de lo mas importante, sin embargo, no solo es eso, es en general revisar y validar las caracteristicas criticas del sistema, ejemplo:
Usabilidad y rendimiento para una app de e-comerce con usuarios no tecnicos
## COMO se valida?
Los metodos, herramientas y procesos concretos que el equipo usara para verificar la calidad, ejemplo: Evaluacion heuristica, cypress, etc.
## CUANDO se acepta?
Los criterios numericos que determinan si el sistema es suficientemente bueno para ser lanzado, ejemplo:
0 defectos criticos. Severidad promedio <2.5, cumplimiento heuristico, etc.
## Analogia:
El menu del restaurante: Que queremos que haga el software?
Protocolo de sanidad: Plan de calidad del desarrollo
